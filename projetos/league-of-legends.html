Interface interativa de seleção

Estudo: League of Legends

Projeto em HTML, CSS e JavaScript que transforma uma base de seleção de personagens em uma experiência visual inspirada em League of Legends, com grid de cards, hover, imagem principal e descrição dinâmica.

HTML CSS JavaScript Interativo Responsivo

Sobre o projeto

Uma tela de seleção com comportamento visual claro, responsivo e controlado por JavaScript.

O projeto organiza cards de campeões, imagem principal, nome e texto de apoio em uma experiência de interface. A proposta era exercitar manipulação de DOM, eventos de mouse, troca de estados visuais e adaptação para telas menores.

Ficha do projeto

Tecnologias
HTML semântico, CSS, JavaScript, manipulação do DOM, eventos de hover, imagens otimizadas, media queries e layout responsivo.
Contexto
Projeto de estudo para praticar uma interface gamer com troca dinâmica de informações e leitura visual imediata.
Interface seção por seção

O case mostra os estados principais da experiência.

Cada bloco registra uma parte do comportamento: tela inicial, seleção de campeão, variação de conteúdo e adaptação mobile.

Interface
01

Tela inicial com grid de campeões e área de personagem em destaque.

A primeira visão separa a escolha dos personagens à esquerda e reserva o lado direito para a leitura do campeão selecionado.

Grid Hero visual Layout
Interação
02

Hover troca imagem, nome e descrição sem recarregar a página.

Ao passar o mouse sobre um card, o JavaScript atualiza a imagem principal e o texto, criando uma resposta imediata para o usuário.

Hover DOM Estado
Variação
03

O mesmo componente sustenta diferentes personagens e textos.

A estrutura permite alternar conteúdos mantendo o mesmo desenho de interface, o que deixa o projeto fácil de ampliar com novos campeões.

Componente Escala Conteúdo
Mobile
04

A versão mobile preserva leitura e escolha em uma tela menor.

A responsividade reorganiza a interface para manter o personagem e os cards legíveis, mesmo quando o espaço horizontal diminui.

Responsivo Mobile Leitura

Notas do case

Problema

Construir uma interface de estudo que não fosse apenas estática, mas que reagisse ao usuário e demonstrasse manipulação de conteúdo com JavaScript.

Solução

Criação de uma tela de seleção com cards, estado ativo, troca de imagem principal, nome e descrição por hover, além de ajustes responsivos.

Resultado

Um projeto visual e navegável que registra conhecimento de HTML, CSS, JavaScript, responsividade e organização de experiência interativa.

Projeto interativo registrado como estudo.
