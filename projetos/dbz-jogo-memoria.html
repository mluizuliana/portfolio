Jogo da memória em JavaScript

Estudo: Jogo da Memória DBZ

Projeto em HTML, CSS e JavaScript com fluxo de login, nome do jogador salvo no navegador, cronômetro, cartas embaralhadas, pares revelados e tabuleiro responsivo inspirado em Dragon Ball Z.

Sobre o projeto

Um jogo simples, visual e funcional para praticar lógica, estado e interação no navegador.

O projeto trabalha com duas etapas: uma tela de entrada para identificar o jogador e um tabuleiro de cartas embaralhadas. A lógica controla pares encontrados, cartas abertas, cronômetro e feedback visual de progresso.

Ficha do projeto

Tecnologias
HTML, CSS, JavaScript, localStorage, DOM, temporizador, eventos de clique, array shuffle, controle de estado, imagens de cartas e layout responsivo.
Contexto
Projeto de estudo para praticar fundamentos de JavaScript por meio de um jogo navegável, com foco em lógica e experiência visual.
Jogo seção por seção

O case registra a jornada completa do jogador.

A apresentação mostra a entrada, o tabuleiro, a revelação das cartas e a leitura em tela menor.

Notas do case

Problema

Transformar um exercício de JavaScript em uma experiência completa, com entrada de jogador, regras simples, estado visual e tabuleiro responsivo.

Solução

Fluxo com login, armazenamento do nome, cards embaralhados, validação de pares, travamento de cartas já encontradas, cronômetro e feedback visual.

Resultado

Um jogo navegável documentado no portfólio, demonstrando lógica de programação, manipulação do DOM, interação e cuidado responsivo.

Projeto de jogo registrado como estudo prático.

A demonstração fica preservada dentro do portfólio para mostrar não apenas layout, mas também lógica funcionando no navegador.
