Sobre o projeto

Uma direção visual que coloca clareza e confiança à frente.

Este é o lado editorial do trio. A página de demonstração explora hierarquia tipográfica, tons neutros, fotografias e blocos de conteúdo para que os projetos possam ser lidos com calma. A direção retrô experimenta o extremo oposto; a híbrida aproxima as duas.

Ficha do projeto

Tecnologias
HTML, CSS, layout responsivo e componentes de interface.
Contexto
Estudo visual de portfólio inspirado no modelo Pet Sitter. Os exemplos apresentados na demonstração são propostas de layout, não cases publicados.
Composição visual

Do primeiro contato aos cards de projeto.

A proposta usa uma primeira dobra ampla e desdobra o mesmo tom em exemplos de apresentação e elementos do sistema visual.

01

Tipografia ampla cria uma entrada serena e legível.

A chamada principal dá prioridade à mensagem, com navegação discreta e bastante espaço para respirar antes da apresentação dos projetos.

Notas do case

Problema

Explorar uma forma de apresentar o portfólio com cuidado visual e leitura confortável, dando espaço aos projetos.

Solução

Combinar tipografia serifada, fotografias, paleta discreta e cards de case com contexto curto.

Resultado

Uma direção editorial navegável que serviu de base para a comparação com o estudo retrô e para a versão híbrida.
